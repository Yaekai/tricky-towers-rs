# The original's text: file format and key names (read 2026-10-05, PC)

Names and format only; no translations here. The game reads the wording at runtime from the
staged `text_<lang>` files (the user's own install).

## Files
`Resources\language\<lang>.txt`, 19 languages: ar, ch, de, en, es, fl, fr, it, jp, ko, nl, no,
pl, pt, ro, ru, sv, tr, tw. English is the fallback when a language file is missing.

## Format
An XML document (UTF-8, CRLF), one `lookup` per key:

```xml
<?xml version="1.0" ...?>
<language ...>
	<lookup>
		<key>DIFFICULTY_EASY</key>
		<translation>...</translation>
	</lookup>
	...
</language>
```

- Read every `/language/lookup`; a lookup without `translation` gives an empty string.
- A literal `\n` (backslash, n) in a translation is a line break.
- `&amp;` and the other XML escapes apply.
- A key that is missing shows as `%KEY%`.
- Placeholders, replaced by the caller: `{medalCount}`, `{targetScore}`, `{playerIndex}`,
  `{subLevel}`, `{cupType}`, `{userName}`, `{username}`, `{controllerName}`, `{xp}`; the time
  format uses `%h%` and `%mm%`.
- Button glyphs are replaced in every string by the current input device's icon (keyboard or
  pad profile): `[continue]`, `[back]`, `[continuePlayerSelect]`, `[start]`, `[invite]`,
  `[store]`, `[gameInfo]` (continue and back swap places in Japanese on pads that swap them),
  and `[controller]` becomes the local word for "controller".
- Arabic (`ar`) is stored left to right and reversed when loaded, keeping `[...]` and `{...}`
  tokens readable.
- The language comes from the system language; unknown ones fall back to English.
