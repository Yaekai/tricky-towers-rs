# Asset lookup audit (2026-10-18)

`TT_LOG_ASSETS=<file>` (DEBUG-TOOL, src/art.rs `Lookup`) writes every art and sound name the game
asked for before a script's `Quit`. 29 offscreen runs (Race/Survival/Puzzle on Easy and Pro with every
spell, the 3 Endless modes, 7 brick packs, 13 menu screens) asked for 870 of the 2,957 staged names.

Limits, so don't read the rest as "unused":
- Offscreen runs load no sounds, so every sound check is unreliable.
- The runs used wizards 1-2 and the default skin only: other wizards, Animal/Indie wizards, other
  brick packs' edge pieces and the controller glyphs show as unasked-for.
- Names built in pieces appear once per variant that happened to be picked.

Names never asked for in any run, after leaving out per-wizard parts, languages, fonts, pad glyphs,
normal maps and pack variants (look at these first; some are asked for by another name):
