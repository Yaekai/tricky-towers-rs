## Tools, as this thread used them
- **Ponytail** (plugin, always on): take the smallest change that is still 1:1.
- **Graphify**: `~/.local/bin/graphify.exe` (not on PATH). `graphify query "..."`,
  `graphify explain X` and `graphify path A B` answer questions before you read whole files. Run
  `graphify update .` after big changes (it was rebuilt at the end of this thread). Never graph
  `extracted\` or `research\`.
- **Readout scripts** (local only, in `research\tools\`; run them with `python -I`):
  - `shader_dis.py Custom_<Name>`: disassembles a shader's D3D9 programs into
    `research\tools\shader_dis\`. The pixel programs are the `_ps.txt` files. Strip NULs with
    `tr -d '\000'` before grepping. Blend states are the `srcBlend`/`destBlend` vals in
    `research\ripped_yaml\...\Shader\<name>.asset` (5/10 = alpha blend, 1/0 = opaque).
  - `uiprefab.py <path under Resources>`: a flat list of a UI prefab's rects, images and texts.
  - `uitree.py <path under Assets> <object>`: one object's subtree with anchors, positions,
    sizes, image slice type and text materials. Pass `_Scenes/<Scene>.unity` for scenes. Set
    `PYTHONIOENCODING=utf-8`.
  - `prefabs.py`: sprite renderers and materials of world prefabs.
- **Decompiled code**: grep `research\ripped\ExportedProject\Assets\Scripts\Assembly-CSharp\`.
  Max's standing rule: read it whenever a 1:1 issue isn't solved at once.
- **Max's clips**: a local recordings folder (`*.mp4`) (1920x1080). Make a contact sheet with
  `ffmpeg -vf "fps=1,scale=192:-1,tile=10x6"` to find a moment, then pull the full frame with
  `-ss`. `clip_1,791,548,470,628.mp4` is a 2-player Puzzle Tiny Cup, with WINNER! at 75 s.
  Max's screenshots are kept locally, outside the repo.
- **Pictures** (headless and silent; never a plain `cargo run`):
  `target\debug\tricky_towers.exe --script X.ron --offscreen <dir> --size 1920x1080`.
  Scripts are lists of `(at: s, run: Cmd)`, using `Start(mode:, difficulty: Some(..),
  opponents: Some(n))`, `Tap(key: "Space"|"Enter"|"Escape"|"Up"|"Down"|"Left"|"Right"|"Tab")`,
  `GiveDark(tower:, spells: [Large])`, `Press(tower:, key: CastDark)`, `Win(tower:)`,
  `Picture(name:)` and `Quit` (docs/debug-tools.md).
  **While Max is gaming on the main card, the run panics with "timed out waiting on the last
  successful submission"**. Prefix it with `WGPU_POWER_PREF=low` to use the Intel chip instead.
- Bash heredocs on this PC eat backslashes, so write Python patches to a file first.
- Unity 9-slice borders are (x=left, y=bottom, z=right, w=top). Our `sliced()` takes
  `[left, right, top, bottom]`. Top and bottom were swapped in several places.
- Unity blends UI in gamma and Bevy in linear light, so a dark overlay at Unity's alpha a looks
  lighter here. About 0.95 matches 0.847 (pause).
